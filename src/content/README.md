# Greeda’s Grange content

These JSON files are now managed through the Decap CMS at `/admin/`.

The client should edit content through the CMS rather than editing these files directly.

- `site.json` — website copy, hero, seasonal banner, navigation, section copy, contact/footer content.
- `booking.json` — direct-booking phone, WhatsApp number, booking labels and pricing rules.
- `rooms.json` — room/lodge details and photos.
- `gallery.json` — featured Sanctuary photos and the full property gallery.
- `amenities.json` — amenities and their images.
- `floraFauna.json` — flora and fauna catalogue.
- `faqs.json` — frequently asked questions.
- `reviews.json` — website guestbook reviews.

Uploaded CMS images are stored under `public/uploads/` and served by Netlify after the normal GitHub-triggered deployment.
